# Context-Fabric

A context-aware shared memory fabric for collaborative mobile robots with deterministic coordination.

## Features

- **Dual Coordination Modes:**
  - ZooKeeper-style (standard ROS 2)
  - Lingua Franca federated (deterministic)
- **Hybrid Architecture:**
  - Control Plane: Task coordination (strong consistency)
  - Data Plane: DSM gossip (eventual consistency)
- **Multi-Device Support:** Deploy across multiple Jetsons

## Build Instructions

### 1. Build Lingua Franca Federates

```bash
cd src/coord
./scripts/build_lf.sh
```

This generates:
- `fed-gen/coordinator/bin/RTI` - Runtime Infrastructure
- `fed-gen/coordinator/bin/federate__fed1` - Coordinator for device 1
- `fed-gen/coordinator/bin/federate__fed2` - Coordinator for device 2

### 2. Build ROS 2 Packages

```bash
cd context-fabric
colcon build
source install/setup.bash
```

## Running Locally (Testing)

### Terminal 1: Start RTI
```bash
./scripts/start-rti.sh 2
```

### Terminal 2: Start Federate 1
```bash
./scripts/start-fed1.sh
```

### Terminal 3: Start Federate 2
```bash
./scripts/start-fed2.sh
```

## Git Workflow

### What to Commit:
- ✅ All `src/` code
- ✅ Build scripts (`scripts/`)
- ✅ Documentation (`docs/`)
- ✅ `.gitignore`

### What NOT to Commit:
- ❌ `fed-gen/` - Generated by LF compiler
- ❌ `bin/` - Compiled binaries
- ❌ `build/`, `install/`, `log/` - ROS 2 artifacts

Users should **rebuild** after cloning:
```bash
git clone <repo>
cd context-fabric
cd src/coord && ./scripts/build_lf.sh && cd ../..
colcon build
```

## Architecture

- **Control Plane:** Lingua Franca federated coordinators (deterministic task allocation)
- **Data Plane:** ROS 2 topics + DSM gossip (state sharing)
- **RTI:** Synchronizes logical time across federates
